# Studio KB Beauty

Site do **Studio KB Beauty**, estúdio de cílios e sobrancelhas na Zona Leste de São Paulo.

Página única, pensada primeiro para o celular, que apresenta os serviços do estúdio, a galeria de resultados e leva a cliente direto para o agendamento pelo WhatsApp.

🔗 [studiokbbeauty.com.br](https://studiokbbeauty.com.br)

**Stack:** Astro · Tailwind CSS · TypeScript · Cloudflare
